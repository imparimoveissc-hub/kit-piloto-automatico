## Quando carregar

- CoS nunca carrega diretrizes profundas para decidir rota.
- Especialista carrega no maximo uma diretriz primaria.
- QA carrega apenas o gate e, se necessario, a diretriz da falha.
- Nicho generico so entra quando altera restricoes, dores, prova ou linguagem da task.

## Quando nao carregar

- Tarefa de ledger, renomeacao, resumo ou organizacao simples.
- Pergunta factual simples.
- Ajuste de formato sem mudanca estrategica.
- Quando o context pack ja contem a informacao necessaria.
