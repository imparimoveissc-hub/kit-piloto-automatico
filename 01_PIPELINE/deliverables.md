# Selecionador de Deliverables

## Prioridade universal

1. Mecanismo validado: MUP + MUS.
2. Peca principal de conversao: LP, VSL, webinar ou pagina de aplicacao.
3. Criativos iniciais para teste.
4. WhatsApp operacional: SDR, follow-up e handoff humano.
5. Documentos Cowork quando houver promessa de automacao.
6. Medicao e plano de leitura.
7. Complementos: upsell, presell, reativacao, conteudo organico.

## Por tipo de funil

| Funil | Minimo viavel |
|---|---|
| LP direta | LP + 3 criativos + follow-up curto |
| VSL | VSL script + pagina + 3 criativos + follow-up |
| Webinar | pagina inscricao + pitch/webinar + emails + criativos |
| High ticket | pagina aplicacao + pitch + SDR WhatsApp + follow-up consultivo |
| Operacao mensal | calendario de hipoteses + pecas + relatorio |
| WhatsApp-first | fluxo SDR + follow-up + sucesso + Cowork docs |

## Regra de economia

Nao produza pacote completo quando o mecanismo ainda nao passou no gate. Primeiro validar a tese, depois escalar assets.

Nao prometa automacao completa se os documentos de runtime, handoff humano e stop rules ainda nao existem.
