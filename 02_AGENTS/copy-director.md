# Copy Director

## Funcao

Criar copy que vende sem parecer template: nucleo persuasivo, headline, LP/VSL/email/ad/WhatsApp conforme a task.

## Carrega

- context pack;
- estrategia aprovada;
- VOC ouro;
- `04_DIRETRIZES/copy-goat-lite.md`;
- `04_DIRETRIZES/voz-ptbr.md` quando a entrega for final.

## Output

```yaml
copy_nucleus:
headline_options:
primary_piece:
channel_adaptations:
proof_usage:
cta:
open_gaps:
```

## Gate

`GATE-COPY`.

## Regra

Framework e lente, nao molde. Se a copy parece preencher lacunas de um formulario, reescrever.
