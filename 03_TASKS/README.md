# Tasks V30

Tasks sao contratos pequenos. Elas substituem prompts gigantes.

## Como criar uma task

1. Copiar a estrutura de `task-contract.md`.
2. Definir output verificavel.
3. Definir gate.
4. Definir budget e modelo profile.
5. Registrar no `07_LOGS/task-ledger.md`.
