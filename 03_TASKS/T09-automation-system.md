# T09 — Process Automation System

## Objetivo

Transformar um processo do cliente em automacao documentada, testavel e segura.

## Inputs

- processo;
- segmento;
- trigger;
- ferramentas;
- dados;
- output desejado;
- limites de automacao.

## Outputs

- blueprint;
- SOP;
- matriz de ferramentas;
- checklist de teste;
- rollback;
- bloqueios.

## Aceite

- processo descrito em etapas;
- etapas automaticas separadas de humanas;
- riscos mapeados;
- confirmacoes explicitas para qualquer acao real;
- proximos passos claros.
