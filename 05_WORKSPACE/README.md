# Workspace

Estado vivo de projetos e clientes.

## Arquivos recomendados

- `current-context.md` - resumo curto do projeto ativo.
- `clientes/` - context packs de clientes quando existirem.
- `projetos/` - projetos avulsos ou campanhas.

## Regra

Cliente especifico vive aqui, nao em `04_DIRETRIZES/`. Diretriz e generica. Contexto de cliente e confidencial e carregado apenas quando a task pede.
