# Checklist - Access Preflight

- [ ] Cliente/projeto identificado.
- [ ] Pasta do kit acessivel.
- [ ] Pasta do cliente criada ou indicada.
- [ ] LP/site informado ou marcado como pendente.
- [ ] Cowork/WhatsApp informado ou marcado como pendente.
- [ ] CRM/agenda informado ou marcado como pendente.
- [ ] Meta `act_id`/CLI validado quando a task envolve trafego.
- [ ] Checkout/analytics informado quando a task envolve funil.
- [ ] Responsavel humano definido para handoff.
- [ ] Limites de automacao definidos.
- [ ] Segredos nao foram colocados em chat, outputs ou logs.
- [ ] Acoes destrutivas continuam exigindo confirmacao humana.
