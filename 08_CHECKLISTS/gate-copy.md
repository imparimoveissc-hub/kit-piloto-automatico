# Checklist - Gate Copy

- [ ] Existe VOC aplicado.
- [ ] Awareness foi considerado.
- [ ] DRE aparece no angulo principal.
- [ ] MUP e MUS estao claros.
- [ ] Promessa tem mecanismo.
- [ ] Provas sao especificas ou gaps estao marcados.
- [ ] Headline tem utilidade, unicidade e especificidade.
- [ ] CTA e claro.
- [ ] Copy nao serve para qualquer nicho.
- [ ] Voz pt-BR natural.
- [ ] Sem travessao longo em copy final.
- [ ] Sem frases genericas de IA.
