# Checklist - Product Promise Audit

- [ ] LP ou pagina de venda foi lida.
- [ ] Claims foram extraidos e classificados.
- [ ] Cada claim tem entrega correspondente ou gap marcado.
- [ ] Promessa de automacao foi comparada com setup real.
- [ ] Promessa de facilidade foi testada contra usuario leigo.
- [ ] WhatsApp/atendimento sustentam a promessa comercial.
- [ ] Cowork/docs existem para automacao prometida.
- [ ] Claims fortes tem prova ou `[A PREENCHER]`.
- [ ] Gaps foram priorizados por severidade.
- [ ] Roadmap de robustez foi criado.
