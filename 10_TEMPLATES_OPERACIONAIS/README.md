# Templates Operacionais

Templates aqui servem para estado, handoff e controle. Nao sao templates de copy.

## Pastas

- `cliente-template/` - contexto minimo de cliente.
- `projeto-template/` - contexto minimo de campanha/funil.
- `output-template/` - pacote final de entrega.
- `task-template.md` - task avulsa.

## Regra

Copie a estrutura quando iniciar trabalho real. Preencha lacunas com `[A PREENCHER]` em vez de inventar.
