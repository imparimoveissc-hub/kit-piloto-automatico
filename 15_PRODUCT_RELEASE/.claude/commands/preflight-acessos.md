# /preflight-acessos

Colete acessos, pastas e limites logo no inicio.

## Execute

1. Pergunte apenas o essencial:
   - onde salvar arquivos;
   - segmento/empresa;
   - WhatsApp/CRM/Cowork, se houver;
   - Meta/analytics, se houver;
   - o que pode rodar automatico;
   - o que exige aprovacao.
2. Crie ou atualize `.claude/config.md`.
3. Liste pendencias bloqueantes separadas de pendencias opcionais.
4. Sugira a primeira tarefa util.

Nunca solicite senha aberta no chat. Oriente o usuario a autenticar ferramentas pelos fluxos oficiais.
