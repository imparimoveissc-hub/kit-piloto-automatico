# /primeira-tarefa

Gere uma primeira entrega util em menos de 15 minutos.

## Execute

1. Leia `PRIMEIRA_TAREFA.md`.
2. Leia `.claude/config.md`, se existir.
3. Escolha uma entrega simples:
   - briefing;
   - proposta;
   - mensagem WhatsApp;
   - follow-up;
   - mini relatorio;
   - plano de 7 dias;
   - template adaptado.
4. Produza algo pronto para revisar e usar.
5. Salve em uma pasta clara quando o usuario permitir escrita.
