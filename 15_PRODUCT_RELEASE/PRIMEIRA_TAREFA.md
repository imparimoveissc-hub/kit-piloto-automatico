# Primeira Tarefa

Objetivo: fazer o aluno ver valor em menos de 15 minutos.

## Fluxo recomendado

1. Rode `/preflight-acessos`.
2. Rode `/setup-nicho`.
3. Responda somente o essencial:
   - segmento;
   - servico principal;
   - publico;
   - maior gargalo;
   - canal principal;
   - se usa WhatsApp.
4. Peça:

```text
Monte minha primeira entrega util usando o kit. Quero algo que eu possa revisar e usar hoje.
```

## Saida esperada

O CoS deve escolher uma destas entregas:

- briefing organizado;
- proposta simples;
- mensagem de WhatsApp;
- follow-up de venda;
- mini relatorio;
- plano de acao de 7 dias;
- template adaptado ao segmento.
- blueprint de automacao em draft.

## Criterio de sucesso

- O usuario entendeu o que foi gerado.
- O arquivo foi salvo em uma pasta facil.
- Existe proximo passo claro.
- Nenhuma automacao real foi ativada sem confirmacao.
