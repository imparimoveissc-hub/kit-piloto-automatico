# Automacoes

Use esta pasta para transformar processos do seu negocio em fluxos operacionais.

## Quando usar

- atendimento;
- onboarding;
- follow-up;
- relatorios;
- suporte;
- financeiro;
- prospeccao;
- entrega de servico;
- atualizacao de CRM;
- organizacao de tarefas.

## Comando

```text
/automatizar-processo
```

## Regra

Tudo nasce como `draft`. O kit pode desenhar, documentar e testar. Ativar automacao real exige confirmacao.

## Saidas esperadas

- blueprint;
- SOP;
- matriz de ferramentas;
- checklist de teste;
- rollback;
- pendencias.
