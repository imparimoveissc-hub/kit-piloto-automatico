# Checklist de Teste Cowork/WhatsApp

Status: draft

## Antes do teste

- [ ] Variaveis preenchidas em `variables.yaml`.
- [ ] Responsavel humano definido.
- [ ] Horario de atendimento definido.
- [ ] Stop rules revisadas.
- [ ] Handoff testado em conversa ficticia.
- [ ] Nenhum envio em massa habilitado.

## Cenarios obrigatorios

- [ ] Lead interessado.
- [ ] Lead sem interesse.
- [ ] Cliente pede preco.
- [ ] Cliente reclama.
- [ ] Cliente pede assunto sensivel.
- [ ] Cliente pede para parar.
- [ ] Agente nao sabe responder.

## Passa quando

- mensagens ficam naturais no celular;
- handoff envia resumo util;
- opt-out funciona;
- nao inventa promessa;
- nao envia nada real sem confirmacao.
