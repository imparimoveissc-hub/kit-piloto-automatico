# Curso Operacional KPA V30

Esta pasta organiza o caminho do aluno.

O curso nao substitui o kit. Ele mostra a ordem certa para usar o kit sem se perder.

## Caminho mais seguro

1. Abra `../index.html` para acompanhar o guia visual.
2. Assista o modulo 00.
3. Instale e abra o Claude Code no modulo 01.
4. Rode `/preflight-acessos`.
5. Rode `/setup-nicho`.
6. Rode `/primeira-tarefa`.
7. Depois escolha entre WhatsApp, automacoes, templates ou trafego.

## Arquivos principais

| Arquivo | Uso |
|---|---|
| `trilha-oficial.md` | ordem recomendada das aulas |
| `aulas/README.md` | mapa aula por aula |
| `tarefas/` | tarefas praticas do aluno |
| `checklist-aluno.md` | validacao final de execucao |

## Regra de ouro

Nao pule a primeira entrega.

Se voce ainda nao gerou uma entrega util com `/primeira-tarefa`, nao comece por WhatsApp, automacao ou trafego.
