# Checklist do Aluno

Use este checklist antes de dizer que o kit esta configurado.

## Instalacao

- [ ] Abri a pasta correta no Claude Code.
- [ ] O Claude conseguiu ler a estrutura do kit.
- [ ] Rodei `/preflight-acessos`.
- [ ] Sei quais acessos ainda dependem de confirmacao.

## Setup

- [ ] Rodei `/setup-nicho`.
- [ ] Tenho uma familia operacional definida.
- [ ] Sei quais templates fazem sentido para meu negocio.
- [ ] Sei qual WhatsApp pack faz sentido para meu caso.
- [ ] Sei qual automacao inicial devo criar.

## Primeira entrega

- [ ] Rodei `/primeira-tarefa`.
- [ ] Recebi uma entrega util.
- [ ] Revisei a entrega com o Claude.
- [ ] Sei qual e o proximo passo.

## WhatsApp

- [ ] Escolhi um fluxo: prospeccao, SDR, CS, follow-up, onboarding ou reativacao.
- [ ] O fluxo esta em modo draft.
- [ ] Existe regra de parada.
- [ ] Existe handoff humano.
- [ ] Testei com conversa ficticia antes de ativar.

## Automacoes

- [ ] Escolhi um processo repetitivo real.
- [ ] Rodei `/automatizar-processo`.
- [ ] Tenho SOP.
- [ ] Tenho blueprint.
- [ ] Sei quais ferramentas precisam de acesso.
- [ ] Nao ativei execucao real sem revisar.

## Rotina semanal

- [ ] Tenho 3 tarefas prioritarias da semana.
- [ ] Sei qual agente/squad deve cuidar de cada uma.
- [ ] Tenho um lugar para salvar outputs.
- [ ] Sei como pedir suporte: print do erro, comando usado e o que esperava receber.
