# Tarefa 01 - Preflight de Acessos

## Objetivo

Preparar o kit para trabalhar com menos interrupcoes.

## Comando

```text
/preflight-acessos
```

## O que responder

Informe:

- onde a pasta do kit esta salva;
- se usa Windows ou Mac;
- quais ferramentas quer conectar;
- se vai usar WhatsApp, trafego, arquivos, Google Drive, CRM ou planilhas.

## Resultado esperado

Uma lista separada em:

- acessos necessarios agora;
- acessos que podem esperar;
- acessos perigosos que exigem confirmacao;
- proximos passos.

## Erro comum

Rodar automacao real antes do preflight.

Correcao: manter tudo em modo draft ate revisar.
