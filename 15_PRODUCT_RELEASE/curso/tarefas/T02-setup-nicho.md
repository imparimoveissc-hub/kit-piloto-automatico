# Tarefa 02 - Setup de Nicho

## Objetivo

Adaptar o kit para o negocio do aluno, mesmo que o nicho nao exista pronto.

## Comando

```text
/setup-nicho
```

## O que responder

Use este formato:

```text
Meu negocio e [DESCREVA].
Eu vendo [PRODUTO/SERVICO].
Meu cliente ideal e [TIPO DE CLIENTE].
Meu processo mais importante hoje e [VENDAS / ATENDIMENTO / ENTREGA / SUPORTE / TRAFEGO].
Minha maior dor operacional e [DOR].
```

## Resultado esperado

- familia operacional;
- preset mais proximo;
- templates recomendados;
- fluxos WhatsApp recomendados;
- automacoes iniciais;
- squad inicial;
- primeira tarefa recomendada.
