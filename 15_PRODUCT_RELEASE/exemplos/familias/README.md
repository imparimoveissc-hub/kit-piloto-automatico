# Exemplos por Familia de Negocio

Use estes exemplos quando o usuario nao souber por onde comecar.

## Como escolher

1. Leia a descricao do negocio do usuario.
2. Escolha a familia mais parecida.
3. Use o exemplo como ponto de partida, nao como regra fixa.
4. Rode `/setup-nicho` para adaptar.
5. Rode `/primeira-tarefa` ou `/automatizar-processo`.
