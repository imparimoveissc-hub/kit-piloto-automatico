# Nichos

Destino oficial dos presets por nicho da release V30.

Origem: presets por nicho do kit-base legado.

Nichos minimos para preservar promessa historica:

- advocacia;
- B2B;
- clinicas.

Cada nicho precisa ter:

- contexto;
- prompts;
- templates;
- riscos/restricoes;
- WhatsApp pack;
- squad manifest inicial.

## Setup adaptativo

Quando o nicho exato nao existir, use:

- `family-classifier.md`;
- `setup-nicho-playbook.md`;
- `config-template.yaml`.

O objetivo e classificar por familia operacional e adaptar templates/WhatsApp/automacoes sem travar o usuario.
