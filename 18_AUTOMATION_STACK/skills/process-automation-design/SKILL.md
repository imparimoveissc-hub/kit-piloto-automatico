# Process Automation Design

Use esta skill quando o usuario quiser automatizar um processo, criar SOP, conectar ferramentas ou transformar uma rotina em fluxo operacional.

## Workflow

1. Leia `18_AUTOMATION_STACK/templates/process-intake.md`.
2. Preencha o minimo com o que o usuario forneceu.
3. Gere `automation-blueprint.yaml`.
4. Gere SOP.
5. Gere matriz de ferramentas/acessos.
6. Gere teste e rollback.
7. Marque tudo como `draft`.

## Nao fazer

- Nao pedir senha no chat.
- Nao executar envio real.
- Nao alterar CRM, campanha, planilha ou ferramenta sem confirmacao.
- Nao vender automacao como perfeita: sempre inclua teste e handoff.
